# Data dictionary

All processed columns are enumerated below. CSV numeric columns use blank NA; IDs are
strings semantically even if a reader infers integers. Ratios are fractions, not
percentage points. Source percentages are retained alongside recomputed ratios.

Raw tables preserve scalar source fields and source_json (exact JSON values, including
Chinese names, nested objects and original percentage strings). Raw players has one
row per player with all season roster versions; roster_memberships has phase/team
membership grain. Caches contain full HTTP responses and are excluded from git.

Team ratings use each side's own estimated possessions, not a symmetric pace estimate.
These are approximate box-score ratings, never player or pairing ratings.
